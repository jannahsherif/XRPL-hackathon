# Mastercard Agent Pay for Machines (AP4M), launched 2026-06-10
Source: https://www.mastercard.com/global/en/news-and-trends/press/2026/june/mastercard-launches-agent-pay-for-machines.html
> The official page returned HTTP 403 to automated fetches. This was built from press coverage.

- Extends Agent Pay (2025, consumer agentic checkout) to **machine-to-machine** payments: automated, high-frequency, low-value (down to fractions of a cent), with no human present at the point of payment.
- **Four functions:** **Credentialing** (agent identity via Verifiable Intent) · **Permissioning** (spend limits and execution rules set ahead of time, enforced programmatically) · **Transacting** (continuous commerce across providers) · **Settlement** (multi-rail: cards, bank accounts, **stablecoins**).
- **Permissions on-chain:** the permissions humans grant to agents are recorded on public blockchains so multiple parties can verify them. Initial chains: Polygon, Solana, Base, "among others" (Fortune).
- **x402:** an Oct 22, 2026 Cloudflare Connect demo (9 payments to 2 providers) was reported as built on the open x402 protocol.
- **Partners (30+):** Adyen, Ant International, BVNK, Checkout.com, Cloudflare, Coinbase, Getnet, Global Payments, OKX, Stripe, Tempo, plus Aave Labs, Alchemy, Anchorage Digital, Basis Theory, Catena, Coinflow, Crossmint, MoonPay, Nevermined, Polygon, Rain, **RippleX** (XRPL ecosystem), Sapiom, Skyfire, Solana Foundation, t54 Labs, Turnkey, Utila.
- **Use cases:** an agent buys a domain, hosting and assets; a logistics agent settles freight, warehouse and cold-chain fees. One human instruction leads to many programmatic payments.
- **Related:** Coinbase x402; Stripe + Tempo Machine Payments Protocol (MPP); Google AP2; Visa agentic tools.
