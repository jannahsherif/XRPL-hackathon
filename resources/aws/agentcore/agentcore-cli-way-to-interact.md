

# AgentCore CLI
<a name="agentcore-cli-way-to-interact"></a>

The AgentCore CLI is a command-line tool for building, deploying, and operating agents and Amazon Bedrock AgentCore resources. Use project workflows to define related resources and deploy them together. Use resource commands to work with individual deployed resources directly. Most resource commands read, list, or invoke resources.

The project commands are `create`, `add`, `remove`, `dev`, `build`, `deploy`, `status`, `invoke`, `logs`, `traces`, and `export`. The resource commands are `eval`, `gateway`, `harness`, `identity`, `memory`, `payment`, and `runtime`. The `feedback`, `config`, and `update` commands manage the CLI itself.

If you are new to AgentCore, start with [Get started with Amazon Bedrock AgentCore](agentcore-get-started-cli.md) to create, test, and deploy your first code-based agent. For an end-to-end workflow that adds memory, tools, policy controls, evaluations, and operations to one project, follow [Tutorial: Build, deploy, and operate an agent](agentcore-cli-get-started.md).
