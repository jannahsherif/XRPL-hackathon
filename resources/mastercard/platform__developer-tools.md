# Developer Tools
source: https://developer.mastercard.com/platform/documentation/developer-tools/index.md

Use this page to choose the tool that matches how you want to test and integrate with APIs. Start with a ready-to-run API client if you want the fastest path to a working Sandbox request.

### Recommended path {#recommended-path}

Use one of these tools depending on your goal:

1. Postman
2. Insomnia

## Tools {#tools}

#### Postman Collection {#postman-collection}

Use a pre-configured Postman collection to authenticate requests, set your base URL, and test endpoints quickly.

[Open the Postman Collection guide](https://developer.mastercard.com/platform/documentation/developer-tools/postman-collection/index.md)

#### Insomnia Collection {#insomnia-collection}

Use ready-to-run Insomnia packages to import requests, configure your environment, and send Sandbox calls without building a client first.

[Open the Insomnia Collection guide](https://developer.mastercard.com/platform/documentation/developer-tools/insomnia-collection/index.md)
