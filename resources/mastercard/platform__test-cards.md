# Test Cards for Mastercard APIs
source: https://developer.mastercard.com/platform/documentation/test-cards/index.md

Mastercard APIs utilize product specific test cards (when applicable). In some cases a Mastercard representative must work with customers directly to configure specific cards for testing.
Note: Mastercard does not offer a generic set of test cards that can be used across products.

## Mastercard Developers Test Cards {#mastercard-developers-test-cards}
