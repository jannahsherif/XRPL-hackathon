# Platform Overview
source: https://developer.mastercard.com/platform/documentation/index.md

## Welcome to Mastercard Developers {#welcome-to-mastercard-developers}

The Mastercard Developers platform is designed to offer a wide range of products that enable you to integrate Mastercard's services into your applications. The platform provides products for various functionalities, including payment processing, fraud prevention, data analytics, and more.

We provide comprehensive documentation, guides, and support to help you integrate seamlessly into your applications. The goal is to simplify the onboarding and integration process along with providing you with the tools and capabilities needed to create innovative solutions using Mastercard's services.

## Mastercard Developers API {#mastercard-developers-api}

The Mastercard Developers API allows you to integrate and interact with the Mastercard Developers portal programmatically, mirroring the functionality of the Developers Dashboard. Any task you perform on the Dashboard can also be done via the API, and changes are reflected in both.
