# Edit Project Details
source: https://developer.mastercard.com/platform/documentation/managing-your-project/editing-project-details/index.md

Project information can include high-level details such as the project name, commercial countries and client-related information.

## Steps for Editing Project Information {#steps-for-editing-project-information}

1. Log in to [Mastercard Developers](https://developer.mastercard.com/account/log-in/). ![log-in](https://static.developer.mastercard.com/content/platform/img/login.png)
2. Select your project from **My projects** page. ![projects](https://static.developer.mastercard.com/content/platform/img/projects.png)
3. Go to **Settings** . ![settings](https://static.developer.mastercard.com/content/platform/img/settings.png)
4. Click **Update** to modify content in the **Project Details** section:
   * Modify the **Project name** if needed. ![Edit Project Name](https://static.developer.mastercard.com/content/platform/img/edit-project-name.png)
   * Add or remove countries from the **Commercial countries** drop-down list. Use the dropdown menu or type the name of a country to add it. ![Edit Commercial Countries](https://static.developer.mastercard.com/content/platform/img/edit-commercial-countries.png)
5. In the **Client Details** section:
   * Add all relevant client details (*company name, id, address, etc.* ). This information can not be changed after submitted. ![Edit Client Details](https://static.developer.mastercard.com/content/platform/img/edit-client-details.png)

Note: For Open Finance projects, you cannot change the project created for yourself into one designated for a client, or vice-versa.
